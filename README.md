# 🌍 Nisar's Multilingual Translator

An AI-assisted translation application that translates text between four languages:

- 🇺🇸 English
- 🇵🇰 Urdu
- 🇸🇦 Arabic
- 🇩🇪 German

The app lets users select one source language and translates the entered text into the other three supported languages.

## Features

- Translation between English, Urdu, Arabic, and German
- One input translated into three target languages simultaneously
- Built with Meta's NLLB-200 Distilled 600M translation model
- Simple, responsive Streamlit interface
- Basic name glossary support for **Nisar Ahmad**
- Clear AI-translation safety notice for important content

## Technology Stack

- Python
- Streamlit
- PyTorch
- Hugging Face Transformers
- Meta NLLB-200 Distilled 600M

## How it works

1. Select the source language.
2. Enter or paste the text you want to translate.
3. Click **Translate into 3 languages**.
4. Review the generated translations.

## Important notice

This tool provides **AI-assisted translations**, not certified professional translations. Quality can vary depending on the language pair, context, sentence length, personal names, idioms, technical terms, and cultural expressions.

Always review translations involving:

- Names, organizations, and locations
- Dates, times, numbers, and money
- Legal, medical, or financial information
- Technical documentation
- Idioms and culturally sensitive content

Do not use this application as the only source for high-stakes or official translations.
